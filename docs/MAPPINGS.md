# Requirements to Code Mapping Matrix

| Feature Requirement | Backend App | Database Table(s) | DRF API Endpoint(s) | Frontend View / Route | Key Constraints / Invariants |
|---|---|---|---|---|---|
| **Multi-Tenancy & Auth** | `apps.accounts` | `users`, `organizations`, `organization_memberships`, `invitations` | `/api/v1/auth/*`, `/api/v1/organizations/*` | `/login`, `/register`, `/organizations`, `/org/:orgSlug/admin/members` | User unique email, unique membership per (org, user), tenant query scoping. |
| **Course Catalog & Authoring** | `apps.courses` | `courses`, `categories`, `course_sections`, `lessons`, `course_prices` | `/api/v1/courses/*`, `/api/v1/sections/*` | `/org/:orgSlug/catalog`, `/org/:orgSlug/courses/:courseId`, `/org/:orgSlug/instructor/courses` | Unique section/lesson positions, course slug unique per org, published/draft status. |
| **Commerce & Entitlements** | `apps.enrollments` | `orders`, `order_items`, `payments`, `entitlements`, `enrollments` | `/api/v1/courses/:id/enroll/`, `/api/v1/checkout/`, `/api/v1/me/enrollments/` | `/org/:orgSlug/courses/:courseId`, `/org/:orgSlug/dashboard` | One active enrollment per user-course, atomic checkout & entitlement grant, server price validation. |
| **Learning & Player** | `apps.learning`, `apps.media_assets` | `lesson_progress`, `course_completions`, `media_assets` | `/api/v1/learning/progress/`, `/api/v1/lessons/:id/playback/` | `/org/:orgSlug/learn/:courseId/:lessonId` | Unique progress per (enrollment, lesson), protected signed playback URLs. |
| **Quizzes & Automated Grading**| `apps.assessments` | `quizzes`, `questions`, `answer_options`, `quiz_attempts`, `quiz_responses` | `/api/v1/quizzes/:id/attempts/`, `/api/v1/quiz-attempts/:id/submit/` | `/org/:orgSlug/quiz/:quizId` | Max attempts enforcement, server-side grading, answer keys hidden from learner API. |
| **Assignments & Instructor Grading** | `apps.assessments` | `assignments`, `assignment_submissions`, `assignment_grades` | `/api/v1/assignments/:id/submit/`, `/api/v1/assignments/submissions/:id/grade/` | `/org/:orgSlug/assignments/:assignmentId`, `/org/:orgSlug/instructor/grading` | Submission versioning, instructor grading permission check, passing score condition. |
| **Live Classes & Attendance** | `apps.live_sessions` | `live_sessions`, `live_session_registrations`, `attendance_records` | `/api/v1/courses/:id/live-sessions/`, `/api/v1/live-sessions/:id/join/` | `/org/:orgSlug/live/:sessionId` | Token generation only for enrolled learners, join/leave duration telemetry. |
| **Engagement: Q&A Forum & Reviews** | `apps.discussions` | `discussion_threads`, `discussion_replies`, `course_reviews` | `/api/v1/courses/:id/discussions/`, `/api/v1/courses/:id/reviews/` | `/org/:orgSlug/courses/:courseId/discussions`, `/org/:orgSlug/courses/:courseId/reviews` | Reviews allowed only for verified enrolled learners, 1 review per student-course. |
| **Course Certificates** | `apps.certificates` | `certificates` | `/api/v1/enrollments/:id/certificate/issue/`, `/api/v1/certificates/verify/:num/` | `/org/:orgSlug/certificates/:certificateId`, `/verify-certificate` | Guaranteed completion predicate: all required lessons complete AND quizzes passed AND assignments passed. |
